# 2. SOFTWARE REQUIREMENTS SPECIFICATION - FUNCTIONAL REQUIREMENTS (FR)
# ------------------------------------------------------------------------------
# FR-01: Interactive Geo-Location Map
#   - Leaflet.js 1.9 interactive map with OpenStreetMap tiles.
#   - Category-colored pin markers across major Pakistani cities.
#   - Interactive pan, zoom, click popup previews, and card-to-map synchronization.
#
# FR-02: Responsive Events Catalog & View Switcher
#   - Dual viewing modes: Split Map & List View and Card Grid View.
#   - Cards display event title, category badge, banner image, date/time in PKT,
#     PKR pricing, venue location, and quick action buttons.
#
# FR-03: Category-Based Filtering
#   - Multi-category filtering across 7 core verticals:
#     Music, Sports, Technology, Art & Culture, Food & Drink, Health & Wellness, Community Service.
#   - Real-time dynamic updates of both event list and interactive map pins.
#
# FR-04: Event Detail Page & Venue Navigation
#   - Dedicated event page with high-resolution image gallery.
#   - Detailed schedule, organizer credentials, venue address, and ticket counter.
#   - Interactive venue map with 1-click Google Maps GPS navigation link.
#
# FR-05: User Registration & Authentication
#   - Secure account registration with Full Name, Email, Password, City, and Phone.
#   - NextAuth.js JWT-based session management and password encryption.
#   - Role-based access control (RBAC) separating Attendees and Super Administrators.
#
# FR-06: Digital RSVP Pass Wallet & QR Ticketing
#   - 1-Click RSVP pass reservation for authenticated users.
#   - Automated generation of unique passcodes (e.g. PK-PASS-...) and QR admission tickets.
#   - Dedicated Pass Wallet modal with full pass details and print pass functionality.
#
# FR-07: Favorites & Bookmarking Engine
#   - 1-Click bookmarking from event cards or detail pages.
#   - Persistent saved events synchronized to user dashboard with 1-click removal.
#
# FR-08: Community Reviews & Star Ratings
#   - 5-Star interactive rating system and community reviews.
#   - Review submission form with client-side and server-side validation.
#
# FR-09: Community Event Proposal & Submission Form
#   - 5-Section comprehensive submission form (Basic Info, Schedule/Pricing, Venue, Banner, Contact).
#   - Validation and automatic queueing into Admin Moderation pipeline.
#
# FR-10: Super Administrator Management Portal
#   - Dedicated Admin Dashboard at /admin/dashboard.
#   - KPI analytics cards: Total Events Listed, Pending Approvals, Total RSVPs, Revenue in PKR.
#   - Tab 1: Event Approval/Rejection moderation queue.
#   - Tab 2: Master Event Directory with search, featured toggle, and delete actions.
#   - Tab 3: Registered Community Accounts directory.
#
# FR-11: Featured Events Management
#   - Super Admin can mark or unmark events as "Featured".
#   - Curated Featured Events grid prominently displayed on the homepage.
#
# FR-12: Multi-Attribute Search & Live Filtering
#   - Live keyword search across title, description, venue, and organizer.
#   - City filter (Lahore, Karachi, Islamabad, Rawalpindi, Peshawar, Faisalabad, Multan, Quetta).
#   - Sort options: Upcoming date, Furthest date, Most Popular/RSVPs, Alphabetical (A-Z).
#
# FR-13: User Dashboard & Profile Management
#   - Centralized Attendee Hub at /dashboard.
#   - Manage active passes, bookmarks, activity timeline, and profile settings.
#
# FR-14: Dual-Mode Resilient Fallback Architecture
#   - Seamless hybrid data layer: auto-connects to Strapi 5 CMS REST API when available,
#     and automatically fails over to in-memory local data store when offline.
