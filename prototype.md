Project: Event Discovery & Community Engagement Platform
Objective
Develop only the frontend prototype using HTML/CSS with either Bootstrap or Tailwind CSS. Include a basic login/logout flow (no backend required). The final project specification includes advanced features, but this assignment focuses only on the UI prototype with login/logout/registration. It is based on the uploaded project proposal. 
Required Pages
•	Landing/Home page
•	Login page
•	Register page
•	Events listing page
•	Event details page
•	Categories page
•	User dashboard (prototype)
Minimum Features
•	Responsive design
•	Navigation bar and footer
•	Login and Logout using localStorage or dummy authentication
•	At least 6 event categories (Music, Sports, Technology, Art & Culture, Food & Drink, Community)
•	Event cards with image, title, date, venue and category
•	Category filtering (frontend only)
•	Search box (frontend filtering)
•	Featured events section
•	Profile dropdown after login
