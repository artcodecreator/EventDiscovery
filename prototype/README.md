# EventDiscovery Pakistan — visual prototype reference

The prototype folder preserves the original branded static HTML reference. It shows the earlier layouts for the home page, events, categories, event details, authentication, user dashboard and admin concepts.

The production application is now in the frontend workspace and uses Next.js. Dynamic events, accounts, RSVPs, favorites, reviews and submissions are managed by the Strapi CMS in the cms workspace.

The static prototype uses local browser data only; it does not authenticate against Strapi or write to the production API. Run the full application using the root README instructions.
