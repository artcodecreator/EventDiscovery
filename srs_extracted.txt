SRS Document

Introduction:The Event Discovery & Community Engagement Platform is a comprehensive web-based application developed to help users discover, explore, and participate in local and online events efficiently. The platform serves multiple user roles including Guest Users, Registered Users, Event Organizers, and Administrators by providing a centralized system for event discovery, registration, management, and community interaction.
The system integrates modern technologies such as interactive maps, responsive interfaces, event categorization, user authentication, and content management systems to provide a seamless user experience. Users can search events by category, location, date, and organizer while administrators can manage events, users, approvals, and analytics through a dedicated dashboard.
This project demonstrates modern software engineering principles including MVC architecture, RESTful APIs, role-based access control, responsive web design, secure authentication, cloud storage integration, and scalable system architecture. 
Scope of Project:
The system will support three primary user roles:
Guest Users – Browse events, search and filter events, and view event details. 
Registered Users – RSVP for events, save favorites, submit reviews, and manage profiles. 
Administrators – Manage users, approve events, manage categories, and oversee the platform.

Adopted Methodology
As per project requirements, the adopted methodology is the VU Process Model.
The VU Process Model is a hybrid software development methodology combining features of:
Waterfall Model 
Spiral Model 
This methodology provides structured development phases with iterative improvements and continuous risk analysis.
VU Process Model:
The VU Process Model combines the sequential structure of the waterfall model with the flexibility and risk management approach of the spiral model. It ensures proper planning, analysis, development, testing, deployment, and maintenance throughout the software development lifecycle.
Phases of VU Process Model
1. Feasibility Study
Analyze technical and operational feasibility 
Identify system requirements 
Conduct cost-benefit analysis 
2. Requirements Definition
Gather system requirements 
Prepare Software Requirements Specification (SRS) 
Conduct stakeholder meetings 
3. System Design
Design system architecture 
Prepare database structure 
Create UI/UX wireframes 
4. Implementation
Develop frontend modules 
Develop backend APIs 
Integrate authentication and database systems 
5. Testing
Unit testing 
Integration testing 
System testing 
Bug fixing 
6. Deployment
Deploy application to production server 
Configure hosting environment 
Final deployment verification 
7. Maintenance
Bug fixes 
Feature updates 
Performance optimization 
Waterfall model:
The Waterfall Model is a linear software development methodology where each phase is completed before moving to the next phase. It includes requirement analysis, design, implementation, testing, deployment, and maintenance. This model ensures proper documentation, structured planning, and organized project management.



Spiral model:
The Spiral Model is a software development approach that combines the features of the Waterfall Model and prototyping. It focuses on repeating the development process in cycles, called spirals, to gradually build the final product.
Each spiral includes four main steps: planning, risk analysis, development, and review. This model is useful for large or high-risk projects because it allows for continuous feedback, early risk detection, and changes to requirements at any stage.
